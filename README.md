# 音阶指型六线谱（Guitar Scale Tab）

浏览器里查吉他音阶指型：选中主音和音阶，直接得到**把位谱**与**每弦三音谱**（3NPS）的六线谱，配一张可点击试听、能反向定位谱上音符的指板图。纯静态页面，不需要构建，也不需要后端。

## 功能

### 音阶与指型

- 19 条音阶，分四类：大小调、教会调式、五声 / 布鲁斯、对称 / 变化音阶（含全音、减音阶、变化音阶等）。
- 12 个主音，可切换升号 / 降号拼写；七声音阶按字母逐级拼写（C 大调一定是 C D E F G A B，不会出现 A#）。
- 两种谱型：**把位**（五格框）与**每弦三音**（3NPS，六弦各三音），可只看其中一种。
- 指型名用首调唱名：do 指型从主音起、re 从二级起……小调按 la 起排，与教材说法对应。
- 最高品可选 12 / 15 / 17。

### 指板图

- 画整条琴颈上的该音阶，主音标红；选中单个指型时，指型外的音淡出，方便和谱对照。
- 点圆点可试听，同时把下方谱上同一个音点亮；点谱上的音符则反向闪指板，并自动滚到可见位置。
- 视图可切「琶音」，只留和弦音，圆点显示 R / b3 / 5 / b7。
- 圆点标签可在音名 / 级数之间切换；播放速度 60 / 90 / 132 BPM。
- 叠加和弦音：红色主音、橙色和弦音、深色纯音阶音三层；和弦根音离开主音时，还会出现虚线橙圈，表示「属于这个和弦、但不在当前音阶里」的紧张音（例如 C 大调上的 E7，G# 就是）。

### 六线谱

- VexFlow 4.2.3 绘制 TAB，可标注级数与指法编号（1–4 指，空弦不标）。
- 内容分三块纵向排列：**把位谱** → **每弦三音指板** → **每弦三音谱**，顶部另有总指板；每块内按指型（do、re、mi…）排列。
- 默认 C 大调全部指型共 21 张卡片：7 把位谱 + 7 三音指板 + 7 三音谱。

### 其他

- 选择会记在 `localStorage`（键名 `scale-tab-state-v3`），下次打开保持上次状态。
- 有打印样式；窗口窄于 760px 时自动切换移动端布局。

## 快速开始

必须通过 HTTP 打开（页面用的是原生 ES module，`file://` 直接双击会被浏览器拦掉）。

macOS 最省事：双击 `启动音阶谱.command`，脚本会从 8771 起找一个空闲端口、起静态服务并打开浏览器，关掉终端窗口即停止。

手动起服务：

```bash
cd scale-tab
python3 -m http.server 8771
# 打开 http://localhost:8771/
```

关于 VexFlow：`index.html` 先加载本地 `lib/vexflow.js`，没有则自动回退到 jsDelivr 上的 VexFlow 4.2.3。所以

- 联网即可直接用，仓库不携带这个大文件；
- 想离线用，把 `vexflow.js`（4.2.3，CJS 构建）放到 `lib/` 下即可。

## 自检

```bash
node tools/verify.mjs            # 全量结构断言，应输出「全部通过」
node tools/check.mjs 0 major 0   # 抽查：主音 pc=0（C）、major、第 0 个指型（do）
```

`check.mjs` 参数为 `<主音pc 0–11> <音阶id> [指型级数索引]`，输出按弦分行、`*` 标主音的品位表。

## 实现上的约定

- **把位边界两条规则**：框画在 `[主音−1, 主音+3]`（五格）；6 弦是指型起点，只收主音及以上，保证第一个音就是该型主音；其余五弦从框左边起全收。
- **同音高只留一个**：相邻两弦差 4 或 5 品时同一个音高会在两根弦上各出现一次，保留主音格右侧的位置，丢掉左侧补充格上的重复音（否则会出现「2、3 弦两个 F」那类错谱）。
- **每弦三音要求音高严格递增**，且每弦正好 3 音；不足 7 个音的音阶（如五声、布鲁斯）要跨三个八度以上，琴颈放不下，因此不生成。

## 浏览器

Chrome / Edge / Safari 最新版。音频走 Web Audio，浏览器要求先有一次用户交互才会出声，所以第一次点击圆点或「播放」才听得到。
